# PokeLid Browser

Personal browsing tool for the Pokémon "Poké Lids" manhole covers: sort and filter by number of Pokémon, region, Pokémon name, color count, color scheme and evolution stage, with evolution family trees.

Pokémon and all related artwork are © Nintendo / Creatures Inc. / GAME FREAK inc. Lid images come from https://local.pokemon.jp/en/manhole/ and Pokémon images from PokéAPI. This is an unofficial, non-commercial fan reference and is not affiliated with or endorsed by The Pokémon Company.
